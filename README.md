\# 🎥 CCTV Human Analysis System



\### Real-Time Computer Vision for Understanding Observable Human Activity



A real-time CCTV Human Analysis System built using Computer Vision and AI technologies.



> \*\*From raw CCTV footage to structured human-analysis data — in real time.\*\*



\## ✨ Key Features



\- 👤 Person Detection

\- 🧍 17-Point Human Pose Estimation

\- 🎯 Multi-Person Tracking

\- 🙂 Face Detection

\- 🧠 Facial-Expression Classification

\- ⚡ Real-Time Video Processing

\- 🖥️ Web-Based Monitoring Dashboard
